# Skill: Compliance Documentation Updater

Use this skill when introducing features that process new user data or external integrations.

## Execution steps

1. Determine new data types and whether external services are involved.
2. Review README/architecture/privacy/operator guidance for needed updates.
3. Draft operator guidance for permissions, retention, and legal responsibilities.
4. Avoid claiming automatic GDPR compliance.
