# Skill: Legal & Open-Source Compliance Auditor

Use this skill to audit README files, UI notices, SECURITY.md, or promotional copy.

## Inspection checklist

1. **No absolute GDPR claims:** Avoid “GDPR-compliant” / “DSGVO-sicher” / “certified”. Clarify **operator responsibility**.
2. **Operator responsibility notice:** Docs state technical guardrails ≠ automatic legal compliance.
3. **License & copyright:** Preserve license/copyright notices.
